# NextPlay

## Descripción
NextPlay es una aplicación web para organizar videojuegos,
descubrir nuevos títulos y planificar qué jugar.

## Objetivos
- Organizar videojuegos pendientes.
- Descubrir nuevos juegos.
- Planificar qué videojuego jugar.

## Tecnologías
- HTML
- CSS
- JavaScript
- Docker
- Git
- GitHub

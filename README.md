
# NextPlay

## Descripción
NextPlay es una aplicación web destinada a ayudar
a los jugadores a organizar sus videojuegos y
descubrir nuevos títulos.

## Justificación
El proyecto surge de la necesidad de organizar
los videojuegos que tenemos pendientes y
encontrar nuevos juegos que puedan interesarnos.

## Objetivos
- Organizar videojuegos pendientes.
- Descubrir nuevos juegos.
- Planificar qué videojuego jugar.
- Facilitar la gestión de nuestra biblioteca.

## Tecnologías
- HTML
- CSS
- JavaScript
- Docker
- Git
- GitHub

## Funcionalidades
- Gestión de videojuegos.
- Recomendaciones de nuevos juegos.
- Planificación de videojuegos pendientes.
